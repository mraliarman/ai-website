# LLM به زبان آدمیزاد

راهنمای فارسی و کاربردی یادگیری و استفاده از مدل‌های زبانی بزرگ (LLM).

## ⭐ حمایت از پروژه

اگر این پروژه برای شما مفید است، لطفاً وارد صفحه GitHub پروژه شوید و با زدن **Star ⭐** از ادامه توسعه آن حمایت کنید:

https://github.com/mraliarman/ai-website

## منبع آموزشی

محتوای آموزشی این سایت بر پایه پروژه متن‌باز `3lf/llm-for-humans` تهیه و برای مخاطب فارسی‌زبان ارائه شده است.

## اجرا

```bash
npm install
npm run dev
```

برای Build تولیدی:

```bash
npm run build
```

برای دریافت آخرین نسخه منبع آموزشی و بازسازی سایت:

```bash
npm run update-source
```

> برای URL نهایی canonical در محیط تولید، متغیر محیطی `SITE_URL` را برابر دامنه واقعی سایت قرار دهید.
